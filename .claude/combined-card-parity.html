Combined mode card parity

The same twelve cards, rendered by SFAF_Shortcodes::render_event_card(), in a list-mode block and in a combined-mode block. Both hosts are 770px, which is the width sfaf.org's template gives the block. At that width the combined mode stacks, so its list panel is full width and every card in it should be identical to the card beside it in list mode.
